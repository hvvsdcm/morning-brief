# 모닝 브리프 — 설계

작성: 2026-09-24. 사용자는 설계 도중 "알아서 해놔"라고 위임했으므로 남은 결정은 아래 기본값으로 확정했다.

## 목표

- 매일 오전 10시(KST) 전에 그날의 핵심 뉴스를 분석한 **신문형 웹페이지**를 발행한다.
- 약 10분 안에 다 읽을 수 있는 분량으로 만든다. 1면 톱과 지면 기사 11~12건, 공백 제외 약 4,600자(분당 500자 기준 9분)에 시장 지표를 훑는 1분을 더한다. 첫 실측에서 15건은 약 12분이 나와 기사 수를 줄였다.
- 휴대폰을 포함한 어느 기기에서든 같은 주소로 읽는다.
- UI/UX는 신문처럼 훑어보기 쉽고, 모바일에서도 편하게 읽혀야 한다. (사용 행태 추적 기능은 넣지 않는다 — 사용자 선택)

## 확정한 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 분석 주체 | 이 PC의 Claude Code CLI(`claude -p --json-schema`) | 사용자 선택. API 비용 없음 |
| 발행 위치 | GitHub Pages(공개 저장소 `main` 브랜치 `/docs`) | 사용자 선택(휴대폰 포함). 무료 |
| 실행 시각 | Windows 작업 스케줄러, 매일 09:20 | 생성 5~10분 + Pages 배포 1~2분 → 10시 전 발행. PC가 꺼져 있었으면 켜지는 즉시 실행 |
| 지면 | 1면 톱, 국내 경제·증시, 글로벌 경제·시장, AI·테크, 정책·사회, 국제·지정학, 시장 지표 패널 | 사용자가 말한 "경제부터 AI, 중요한 정보"를 모두 덮는 최소 구성 |
| 기본 테마 | 다크, 종이(라이트) 전환 가능 | 사용자 디자인 지침(`Desktop/Claude/docs/DESIGN.md`) |

## 구조

```
collect(RSS 27개) ─┐
markets(Yahoo)   ─┼─> prompt ─> claude -p (JSON 스키마) ─> finalize(출처 검증) ─> data/editions/날짜.json
                   │                                                              │
                   └──────────────────────────── build(정적 HTML) <───────────────┘
                                                        │
                                                   docs/ ─> git push ─> GitHub Pages
```

- `src/collect.mjs` — 피드 수집, 최근 30시간 필터, 중복 제거, 기사마다 짧은 id(`n1`…) 부여.
- `src/markets.mjs` — 코스피·코스닥·S&P500·나스닥·다우·원달러·엔달러·달러인덱스·미 10년물·WTI·금·비트코인·VIX·닛케이. 전일 대비 변화와 1개월 추이(스파크라인).
- `src/prompt.mjs` — 편집 지침 + 기사 목록 + 시장 수치 + 출력 스키마.
- `src/ai.mjs` — `claude` 실행(도구 비활성, 세션 저장 안 함, 안전 모드). 실패 시 1회 재시도.
- `src/edition.mjs` — AI 출력 검증. **AI는 URL을 쓰지 않고 입력 기사 id만 인용**한다. 존재하지 않는 id는 버리고, 출처가 하나도 남지 않은 기사는 지면에서 뺀다. 1면 톱에 출처가 없으면 발행 실패로 본다. 시장 숫자는 AI가 아니라 수집 데이터로만 표시한다.
- `src/render.mjs` — 순수 함수로 HTML 생성. 모든 외부 텍스트는 이스케이프한다.
- `scripts/daily.mjs` — 전체 실행. 같은 날짜 호가 이미 있으면 건너뛴다(`--force`로 재생성).
- `scripts/build.mjs` — 모든 호를 `docs/`로 렌더(최신 호 = `index.html`, 지난 호 = `editions/날짜.html`, `archive.html`).

## 화면(UX)

- 상단 고정 바: 제호, 읽기 진행률 막대, **남은 읽기 시간**, 글자 크기, 테마 전환, 지난 호.
- 제호 영역: 날짜·요일, 제 N호, 예상 읽기 시간, 발행 시각.
- "3분 요약": 오늘 꼭 알아야 할 것 3~5줄. 바쁜 날은 이것만 읽어도 된다.
- 시장 지표: 카드 그리드. 한국 관례대로 상승은 빨강·하락은 파랑이며, 색만으로 전달하지 않도록 화살표 아이콘과 부호 텍스트를 함께 쓴다. 한 달 추이 스파크라인과 짧은 해설을 붙인다.
- 1면 톱: 큰 명조 제목, 부제, 본문, "왜 중요한가", "지켜볼 점".
- 지면별 기사: 요약 → 분석 → 시사점 → 출처 링크 순서. 데스크톱은 2단, 모바일은 1단.
- 곁가지: 오늘의 체크포인트(기사에 나온 일정만), 용어 풀이.
- 지면 목차 칩: 현재 읽는 지면 강조, 가로 스크롤.
- 오늘 호가 없을 때: 10시 전이면 "10시 발행 예정", 이후면 "아직 발행 전 — 최근 호 표시" 안내.
- 접근성: 본문 대비 4.5:1 이상, 키보드 탐색, 본문 바로가기 링크, 시맨틱 `article/section/nav`, 움직임 줄이기 설정 존중.

## 실패 처리

- 피드 일부 실패: 건너뛰고 로그에 남긴다. 성공한 피드가 5개 미만이면 중단한다.
- 시장 데이터 실패: 해당 지표만 빼고, 모두 실패하면 패널을 숨긴다.
- AI 실패·검증 실패: 1회 재시도 후 중단한다. 사이트는 직전 호를 유지하고, 화면 안내 배너가 날짜 불일치를 알린다.
- 모든 실행 로그: `logs/날짜.log`.

## 검증

- 단위 테스트(`node --test`): 피드 파싱(RSS/Atom), 출처 검증 규칙, 읽기 시간, HTML 이스케이프, 시장 변화율 계산.
- 실제 1회 실행으로 오늘 호를 생성해 모바일·데스크톱 폭에서 브라우저로 확인한다.
